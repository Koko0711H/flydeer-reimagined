# FRS POWER 福瑞斯 · 让动力走得更远

完全独立的新网站。未修改原 shenchai-main 项目及其 GitHub 仓库。中文 / English，白、浅灰、炭黑与福瑞斯 Logo 红；现有产品影像、工厂素材、案例图片与 GLB 模型复用，联系方式保持原样。

## 本地开发

Node.js ≥ 22.13，npm。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5180
```

## 验证与构建

```sh
npm run typecheck
npm run lint
npm run build
npm test
```

稳定本地预览（先停止开发服务）：`npm exec vite -- preview --host 127.0.0.1 --port 5180 --outDir dist/client --strictPort`。

Vinext 静态导出位于 `dist/client`。任何支持 HTML clean URLs 的静态托管均可使用此目录；部署配置在 `.openai/hosting.json`。不依赖原站服务或原仓库。

## 页面

- `/`：贯穿整页的八幕旅程、五类产品切换、产品视频、四行业、七应用场景及联系。
- `/products` 与 `/products/:id`：五类产品、集装箱方案，以及可按七个发动机品牌、50/60 Hz、型号或功率筛选的画册参数。
- `/showroom`：按需加载产品 3D 模型，可拖动、键盘旋转、重置与暂停。
- `/about`：品牌介绍及局部下滑驱动横向制造流程。
- `/cases`：分类筛选、案例场景说明弹窗。
- `/news`：真实空状态，不编造新闻。
- `/service`：现有联系方式、邮件草稿、常见问题。
- `?lang=en` 切换英语；偏好保存在设备上。

## 动效与可访问性

首页由同一个全屏场景贯穿八章：品牌 → 产品选型 → 制造吊装 → 正面细节 → 入箱交付 → 行业运输 → 现场应用 → 联系。主导航进入首页对应章节，详情、自由 3D、新闻及服务表单保留独立路由。

自行制作的 Blender 透明序列共430帧（原始144帧时间线按三分之一帧采样）：机组 → 吊起 → 转正 → 撤吊具、入箱 → 完整卡车侧面 → 俯视。前330帧从原1000×714画幅向上补渲2200像素，成为1000×2914；其余100帧保持原尺寸。Canvas按原始底部画幅定位，模型比例和镜头位置不变，吊具可以伸出原来的矩形边界；模型容器不做裁切。网页控制主体跨屏位置、尺度与出画，实拍工厂从后景展开，卡车沿白色与深色区域的交界行驶，俯视镜头进入应用照片，最后收束到真实交付与联系方式。全部位置由文档滚动绝对求值，可倒滚、直接跳章。三维运输是流程演示，不是施工吊装方案。

Canvas最多3个在途请求和2个解码任务；已下载的压缩帧保留在内存，解码窗口按像素内存预算收缩：当前桌面邻近±3帧，手机±2帧，另保留已显示帧。手机扩展帧解码尺寸640×1865，原尺寸帧为640×457；淘汰和退出时关闭Bitmap。当前已保留Bitmap上限约89MiB/28MiB（桌面/手机），不含Canvas、浏览器临时解码空间和压缩缓存。跳章优先加载目标邻近帧，倒滚复用下载，超时最多一次自动重试，失败可手动重试。八章均为160svh，主体位置、尺度与动作进度使用不越界的连续速度插值。滚动时始终清屏后绘制最近的一张整数帧，不叠加相邻姿态，也不延迟到停止后再变清晰；镜头位置和缩放仍连续插值，没有静止绘制循环。文字在各自视口位置停留、淡出，避免滑入卡车区域。禁止整段同时解码。减少动态偏好、高度≤620px或宽≤760px且高≤740px使用普通文档与关键帧，所有产品、视频、案例弹窗继续可用。无JavaScript也能阅读内容和导航。

GSAP/Lenis保留全站可选平滑滚动和其他路由动画；首页不再挂载旧Company或KineticCases局部时间轴。视频可暂停，弹窗停止背景滚动。Three.js只在用户打开展厅模型时加载，离屏不渲染，失败可退回产品视频。

参见 `THIRD_PARTY.md` 和 `public/licenses`。原始图片预先压缩为 WebP，显式尺寸与懒加载；静态导出无需图片服务，因此保留原生 img。原生页面链接有意采用完整导航，以保证滚动场景清理与独立页面回退。代码检查排除未修改的 shadcn 组件库及其 use-mobile 工具、编译后的 Draco 第三方解码器；所有自编代码仍参与检查。

## 内容与安全

网站不接收或保存询价数据，表单只在本机生成邮件草稿，由访客在邮件客户端确认发送。保留原站邮箱拼写，不擅自更改。没有后台、生产服务器凭据或第三方追踪。

产品范围仅用于初步选型；配置以确认的技术文件为准。案例为原站场景素材，不新增客户名称、项目参数、星级评价或未经核实的认证。原项目不作为新站运行时依赖。

`tests/site.test.mjs` 验证导出页面、链接、素材、联系方式及 GLB 完整性；`tests/story.test.mjs` 验证章节跳转、倒滚、等长节奏、镜头速度连续、不越界和430帧完整性；`tests/frame-sequence.test.mjs` 模拟请求、解码、单帧清晰绘制和资源释放的生命周期；这不等同于人工浏览器视觉验收。
