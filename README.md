# FRS POWER 福瑞斯 · 让动力走得更远

完全独立的新网站。未修改原 shenchai-main 项目及其 GitHub 仓库。中文 / English，白、浅灰、炭黑与福瑞斯 Logo 红；复用现有工厂素材与案例图片，标准开架机组采用用户提供的精修 Blender 模型，联系方式保持原样。

## 本地开发

Node.js ≥ 22.13，npm。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5180
```

## 验证与构建

```sh
npm run typecheck
npm run lint
npm run build
npm test
```

稳定本地预览（先停止开发服务）：`npm exec vite -- preview --host 127.0.0.1 --port 5180 --outDir dist/client --strictPort`。

Vinext 静态导出位于 `dist/client`。任何支持 HTML clean URLs 的静态托管均可使用此目录；部署配置在 `.openai/hosting.json`。不依赖原站服务或原仓库。

## 页面

- `/`：贯穿整页的八幕旅程、三类产品与整段模型动画联动、三维详情、四行业、七应用场景及联系。
- `/products` 与 `/products/:id`：产品类型（保留旧详情路由）与集装箱方案，以及可按七个发动机品牌、50/60 Hz、型号或功率筛选的画册参数。
- `/showroom`：按需加载产品 3D 模型，可拖动、键盘旋转、重置与暂停。
- `/about`：品牌介绍及局部下滑驱动横向制造流程。
- `/cases`：分类筛选、案例场景说明弹窗。
- `/news`：真实空状态，不编造新闻。
- `/service`：现有联系方式、邮件草稿、常见问题。
- `?lang=en` 切换英语；偏好保存在设备上。

## 动效与可访问性

首页由同一个全屏场景贯穿八章：品牌 → 产品选型 → 制造吊装 → 正面细节 → 入箱交付 → 行业运输 → 现场应用 → 联系。主导航进入首页对应章节，详情、自由 3D、新闻及服务表单保留独立路由。

自行制作的 Blender 透明序列共430帧（原始144帧时间线按三分之一帧采样）：机组 → 吊起 → 转正 → 撤吊具、入箱 → 完整卡车侧面 → 俯视。v6从精修母版重新渲染，每张图仅存储完整可见设备所占的区域，原生最长边约1600像素，保留透明边缘，再以WebP压缩。manifest的1000×714为统一逻辑坐标，不是实际图片分辨率；`crops`、`imageSizes`声明每张图的精确位置和原生尺寸。所有430帧与metadata必须整套安装，不能混用不同版本。

电脑端以连续物理坐标计算构图，并抵消每张源图安全相机的缩放和位移。滚动直接更新播放目标；某张帧晚到时，在当前姿态与目标之间选择已经就绪的临近帧，不越过目标后回跳。远距离跳转等待目标附近的画面，不逐帧补播，不增加独立限速追赶或反复等帧门控。道具入退场采用同一机械姿态的整件透明度变化，不混合相邻时间帧，不启用运动模糊。

2026-09-11连续性修正：manifest的`referenceCameraSpans`保留430个原始相机跨度。每个视口先规划整段镜头，再沿连续曲线取样；不在卡车出现时把“整辆车的宽度”重新当成“机组宽度”。吊装至入箱单调拉远，吊具离场后缓慢推近跟车，每个细分帧的对数缩放变化≤0.012。平移也提前规划并约束完整画面及行业文案边界。展厅的描述、参数先退出，标题保留至镜头转场，避免机组压到文字。当前高清图片、正确首页朝向及机械动作不变。

Canvas最多3个在途请求和2个解码任务。已下载压缩帧复用，解码窗口按各张图的真实像素计算；桌面/手机分别使用100MiB/24MiB预算，包含已显示帧和在途解码，另有Canvas与压缩缓存。桌面按原生尺寸解码（上限长边2000），手机长边上限960；不把小图插值冒充高清图。淘汰、离屏和卸载时释放Bitmap。静止时不反复重绘，滚动时清屏后只画一张完整不透明整数帧。请求失败可重试，减少动态偏好、高度≤620px或宽≤760px且高≤740px使用普通文档与静态关键帧。八章仍各160svh，工厂、运输、现场与联系内容随滚动衔接；文字保持独立可读位置，所有功能可在普通文档模式和无JavaScript时访问。

GSAP/Lenis保留全站可选平滑滚动和其他路由动画；首页不再挂载旧Company或KineticCases局部时间轴。视频可暂停，弹窗停止背景滚动。Three.js只在用户打开三维详情或展厅模型时加载，离屏不渲染，失败可退回对应产品的外观预览。展厅相机根据模型包围球与屏幕宽高重新确定距离，拖动旋转和重置后仍保留边距。

## 三产品联动（2026-09-14）

主页、展厅、产品目录和询价选项只列开架、静音箱、集装箱三类，稳定 ID 分别为 `open-frame-small`、`silent`、`container`。产品名称、范围、说明采用画册可见页面，来源与口径见 `PRODUCT_SOURCES.md`。开架 20–2,000 kW、静音箱 20–600 kW，集装箱按项目配置；三维模型的外观不是全系列的统一铭牌参数。

`?product=silent` 或 `?product=container` 保存当前选型。点击左侧按钮同步切换说明、右侧机组、后续吊起/转向/装车/运输、普通文档模式关键图和三维详情。顶部章节导航、语言切换与倒滑保留选型；从展厅和产品详情返回首页时也携带所选产品。更换产品不重建章节滚动布局。`lib/story-variants.ts` 的版本号和取消机制阻止旧请求回写，切换时释放旧播放器与已解码图，只运行所选产品的一套播放缓存。

开架保留原有高清序列；静音箱和集装箱使用用户提供的最终 BLEND/GLB 外观。静音箱进入运输货柜；集装箱机组作为完整货物直接吊到卡车底盘，吊具避开顶部排烟装置，不再套进另一只货柜。新序列位于 `public/media/story/silent/` 和 `container/`，每套由完整430帧、`manifest.json`、海报和五张章节静态图组成，沿用同一时间映射和连续相机补偿。原模型文件不被改写，网站只使用独立压缩资产。集装箱前半段使用独立的文字区域约束，保持左侧53%的区域供标题与选项使用，进入装车段时连续放开；这一布局不改变模型几何或既有开架构图。

新三维 GLB 保留零件和三角面数量，Draco压缩后静音箱约6.76 MB、集装箱约3.81 MB。网页版仅在打开展示时加载三维引擎；加载失败展示当前选型的真实海报。旧产品详情链接保留兼容，静音与集装箱详情不再请求旧影片或不存在的视频。

`tests/product-switch.test.mjs` 与 `tests/story-product-stage.test.mjs` 检查真实选择/播放器生命周期，包括连点、重试、晚到响应、减少动态、无Canvas、首帧和释放。`tests/story-navigation.test.mjs` 检查跨页返回、首页导航与语言切换中的选型。`tests/product-sequences.test.mjs` 检查两套帧的完整性、原生尺寸与全部画面的正反向边界。

## 精修机组模型（2026-09-10）

标准开架机组的网页模型、环绕视频、首页吊装入箱序列及静态关键帧，统一来自用户提供的《发电机组_四视图细节优化.blend》。原文件保持不变；导出排除隐藏备份、参考图片、相机和灯光，应用几何节点修正并保留精修零件。网页版本单独进行贴图压缩与 Draco 几何压缩：208个机组对象、1,349,999个三角形、最大2048像素的内嵌WebP贴图，文件8,264,232字节（约7.88MiB）。仅简化扫描主体，新增精修几何全部保留。6秒环绕视频为1000×714、30fps、H.264，1,775,242字节。展厅默认展示散热器与控制侧，并为这一模型设置独立光照，保留红黑漆面。

首页沿用原来的430帧时间映射，整套帧重新按完整主体构图渲染。首页开场朝向为120°，同时展示控制面板与散热器；在第34源帧接回原机械转向曲线。根据新机组宽度调整下部吊索连接点，主体长轴和落地位置与原动画对齐。全部430帧采用Cycles 16采样、原生透明通道及WebP quality 90重渲；吊具有效阶段另做红色横杆像素检查。渲染缓存加入内容签名和续跑校验。不开启运动模糊，不叠加不同帧。可编辑场景、导出与渲染脚本、模型压缩及素材校验记录保存在独立的“FRS_POWER_模型替换源文件”文件夹，网站仅包含运行必需的压缩素材。

参见 `THIRD_PARTY.md` 和 `public/licenses`。原始图片预先压缩为 WebP，显式尺寸与懒加载；静态导出无需图片服务，因此保留原生 img。原生页面链接有意采用完整导航，以保证滚动场景清理与独立页面回退。代码检查排除未修改的 shadcn 组件库及其 use-mobile 工具、编译后的 Draco 第三方解码器；所有自编代码仍参与检查。

## 内容与安全

网站不接收或保存询价数据，表单只在本机生成邮件草稿，由访客在邮件客户端确认发送。保留原站邮箱拼写，不擅自更改。没有后台、生产服务器凭据或第三方追踪。

产品范围仅用于初步选型；配置以确认的技术文件为准。案例为原站场景素材，不新增客户名称、项目参数、星级评价或未经核实的认证。原项目不作为新站运行时依赖。

`tests/site.test.mjs` 验证导出页面、链接、素材、联系方式及 GLB 完整性；`tests/story.test.mjs` 验证章节跳转、倒滚、等长节奏、镜头速度连续、不越界和430帧完整性；`tests/frame-sequence.test.mjs` 模拟请求、解码、单帧清晰绘制和资源释放的生命周期；这不等同于人工浏览器视觉验收。
