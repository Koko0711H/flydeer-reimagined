# FlyDeer · 动力新视界

完全独立的新网站。未修改原 shenchai-main 项目及其 GitHub 仓库。中文 / English，深蓝、蓝、冷白与品牌红；现有产品影像、工厂素材、案例图片与 GLB 模型复用，联系方式保持原样。

## 本地开发

Node.js ≥ 22.13，npm。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5180
```

## 验证与构建

```sh
npm run typecheck
npm run lint
npm run build
npm test
```

Vinext 静态导出位于 `dist/client`。任何支持 HTML clean URLs 的静态托管均可使用此目录；部署配置在 `.openai/hosting.json`。不依赖原站服务或原仓库。

## 页面

- `/`：首页，原视频、产品切换、行业场景、圆角空间案例画廊。
- `/products` 与 `/products/:id`：五类产品及说明。
- `/showroom`：按需加载原站 3D 模型，可拖动、键盘旋转、重置与暂停。
- `/about`：品牌介绍及局部下滑驱动横向制造流程。
- `/cases`：分类筛选、案例场景说明弹窗。
- `/news`：真实空状态，不编造新闻。
- `/service`：现有联系方式、邮件草稿、常见问题。
- `?lang=en` 切换英语；偏好保存在设备上。

## 动效与可访问性

GSAP + ScrollTrigger 驱动首屏镜头、五款机组三维展台、制造照片连续转场、圆角空间案例画廊与子页面章节；Lenis 仅提供可选桌面平滑滚动。产品和案例场景使用原生 sticky，不截断滚轮；也可以点选产品、拖动案例、使用方向键。手机保留滚动动效，短屏自然排版，减少动态偏好关闭自动运动与滚动绑定。视频可暂停，弹窗打开时停止背景滚动。Three.js 在首页产品区接近视口或用户打开 3D 展厅时加载，离屏不渲染。未拷贝第三方网站设计。

参见 `THIRD_PARTY.md` 和 `public/licenses`。原始图片预先压缩为 WebP，显式尺寸与懒加载；静态导出无需图片服务，因此保留原生 img。原生页面链接有意采用完整导航，以保证滚动场景清理与独立页面回退。代码检查排除未修改的 shadcn 组件库及其 use-mobile 工具、编译后的 Draco 第三方解码器；所有自编代码仍参与检查。

## 内容与安全

网站不接收或保存询价数据，表单只在本机生成邮件草稿，由访客在邮件客户端确认发送。保留原站邮箱拼写，不擅自更改。没有后台、生产服务器凭据或第三方追踪。

产品范围仅用于初步选型；配置以确认的技术文件为准。案例为原站场景素材，不新增客户名称、项目参数、星级评价或未经核实的认证。原项目不作为新站运行时依赖。

`tests/site.test.mjs` 验证导出页面、链接、素材、联系方式及 GLB 完整性；这不等同于人工浏览器视觉验收。
